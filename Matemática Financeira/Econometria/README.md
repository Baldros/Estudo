# Econometria

Econometria usa modelos estatísticos para quantificar relações econômicas, testar hipóteses e produzir previsões. O tópico exige atenção simultânea à teoria econômica, à identificação e ao processo gerador dos dados.

## Por que estudar

Uma análise econométrica bem formulada diferencia associação de interpretação causal, torna explícitas as hipóteses do modelo e permite medir a incerteza das conclusões.

## Livros

- *Using R for Introductory Econometrics* - acompanha um curso introdutório de econometria com implementação, diagnóstico e reprodução de exemplos em R.
- *Using Python for Introductory Econometrics* - transpõe os exercícios e fluxos econométricos para Python e seu ecossistema científico.
- *Using Julia for Introductory Econometrics* - apresenta os mesmos fundamentos com implementações em Julia, favorecendo comparação entre teoria e código.
