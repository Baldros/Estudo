# Espaços Métricos

Espaços métricos formalizam a noção de distância e permitem tratar convergência, continuidade, completude e compacidade em um contexto mais geral que a reta ou o espaço euclidiano.

## Utilidade

O tópico cria a ponte entre análise elementar, topologia e análise funcional, oferecendo uma linguagem comum para muitos argumentos de aproximação.

## Livro

- *Espaços Métricos* - texto dedicado às propriedades de métricas, sequências, continuidade, completude e compacidade.
