# Teoria das Categorias

Teoria das categorias estuda objetos por meio de suas relações e transformações. Categorias, functores e transformações naturais revelam padrões compartilhados entre diferentes estruturas matemáticas.

## Utilidade

Essa linguagem organiza abstrações em álgebra, topologia, lógica e ciência da computação, especialmente composição, tipos e construções universais.

## Livros

- *Category Theory for Programmers* - Bartosz Milewski - introduz ideias categoriais a partir de funções, tipos e programação funcional.
- *Teoria das Categorias* - texto geral sobre conceitos e construções fundamentais; a autoria não aparece no nome do arquivo.
