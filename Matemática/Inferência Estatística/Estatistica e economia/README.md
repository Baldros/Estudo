# Estatística e Economia

Este subtópico reúne aplicações de inferência estatística a dados econômicos, empresariais e experimentais, incluindo respostas categóricas e testes controlados.

## Livros

- *Categorical Data Analysis* - Alan Agresti - referência sobre modelos para dados categóricos, tabelas de contingência e regressão logística.
- *Statistics for Economics, Accounting and Business Studies* - Michael Barrow - introdução aplicada à análise de dados e inferência em economia e negócios.
- *Online Controlled Experiments and A/B Testing* - texto sobre desenho, métricas e análise de experimentos em produtos e serviços.
- *James K. Lindsey 1989* - obra mantida com identificação parcial; o nome do arquivo não permite atribuir título ou escopo com segurança.
