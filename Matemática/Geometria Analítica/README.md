# Geometria Analítica

Geometria analítica traduz objetos geométricos em coordenadas e equações. Retas, planos, distâncias, cônicas e superfícies passam a ser estudados com ferramentas algébricas e vetoriais.

## Utilidade

Essa linguagem é base para cálculo multivariável, álgebra linear, computação gráfica, mecânica e modelagem espacial.
