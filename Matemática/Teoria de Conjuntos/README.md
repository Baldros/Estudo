# Teoria de Conjuntos

Teoria de conjuntos estuda coleções, relações, funções, cardinalidade e os fundamentos formais sobre os quais grande parte da matemática moderna é construída.

## Utilidade

O tópico fornece linguagem para definir estruturas matemáticas e também investiga infinitude, paradoxos e sistemas axiomáticos necessários para evitar contradições.

## Livros

- *Elements of Set Theory* - Herbert Enderton - introdução rigorosa a axiomas, relações, ordinais, cardinais e princípios de construção da teoria de conjuntos.
- *Naive Set Theory* - Paul Halmos - apresentação curta e conceitual da linguagem de conjuntos usada cotidianamente por matemáticos.
