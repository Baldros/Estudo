# Estatística Não Paramétrica

Estatística não paramétrica reúne métodos que dependem menos de formas distribucionais rígidas. Muitos procedimentos usam postos, sinais, permutações ou estimadores flexíveis.

## Utilidade

Essas técnicas são úteis para amostras pequenas, dados ordinais, distribuições assimétricas e situações em que modelos paramétricos não são sustentáveis.

## Livros

- *Practical Nonparametric Statistics* - W. J. Conover - referência aplicada sobre testes baseados em postos, tabelas de contingência e comparações entre grupos.
- *Nonparametric Statistics* - texto geral sobre inferência semiparamétrica e não paramétrica; a autoria não está identificada no nome do arquivo.
