# Ciência de Dados

Ciência de dados integra estatística, computação e conhecimento de domínio para transformar dados em descrições, previsões e decisões. O tópico inclui preparação de dados, modelagem, avaliação e comunicação de resultados.

## Por que estudar

Uma prática sólida exige mais do que aplicar algoritmos: é preciso compreender como os dados foram produzidos, medir incerteza, evitar vazamento e vieses e comunicar conclusões de modo compatível com as evidências.

## Livros

- *Foundations of Data Science* - desenvolve fundamentos matemáticos e algorítmicos para trabalhar com dados de alta dimensão, amostragem, redução de dimensão, aprendizagem e grafos.
- *Data Science from Scratch* - Joel Grus - constrói conceitos e algoritmos básicos em Python para tornar explícita a mecânica por trás das bibliotecas.
- *R for Data Science* - Wickham e Grolemund - organiza importação, transformação, visualização, modelagem e comunicação de dados no ecossistema tidyverse.
- *Python for Data Analysis* - Wes McKinney - referência prática para manipulação, limpeza e análise tabular com pandas, NumPy e notebooks.
- *Practical Statistics for Data Scientists* - apresenta amostragem, testes, regressão, classificação e experimentação com foco nas decisões recorrentes em projetos de dados.
- *Introduction to Data Mining* - cobre preparação, classificação, associação, agrupamento e avaliação de padrões em grandes conjuntos de dados.
- *Linear Algebra for Data Science* - concentra matrizes, projeções, decomposições e geometria linear usadas em modelos e redução de dimensão.
- *Deep Learning for Finance* - discute arquiteturas neurais e aplicações financeiras, com atenção a séries, risco e dados de mercado.
- *Storytelling with Data* - Cole Nussbaumer Knaflic - mostra como escolher gráficos, reduzir ruído visual e construir narrativas que tornem uma análise compreensível.
- *The Data Warehouse Toolkit* - Kimball e Ross - referência sobre modelagem dimensional, fatos, dimensões e padrões para armazéns de dados analíticos.
