# Estruturas de Dados

Estruturas de dados estudam formas de organizar informação para que operações como busca, inserção, remoção e ordenação sejam corretas e eficientes. O tópico se apoia em análise de algoritmos e em invariantes que preservam o comportamento das estruturas.

## Por que estudar

A escolha da representação influencia diretamente tempo, memória e clareza de um programa. O estudo também desenvolve raciocínio sobre complexidade e correção.

## Livro

- *Introduction to Algorithms* - Cormen, Leiserson, Rivest e Stein - referência abrangente sobre análise assintótica, estruturas de dados, ordenação, grafos, programação dinâmica e diversas classes de algoritmos.

Os demais PDFs são provas e materiais de avaliação, úteis para praticar análise e implementação sob problemas concretos.
