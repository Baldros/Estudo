# Provas de Mestrado

Esta pasta reúne provas anteriores usadas como preparação para processos seletivos de mestrado.

## Como usar o acervo

As provas estão organizadas por ano, de 2003 a 2020, com algumas lacunas. Elas permitem identificar recorrência de conteúdos, calibrar tempo de resolução e diagnosticar pontos que exigem revisão.

Uma estratégia útil é resolver cada prova sob limite de tempo, registrar os erros por tópico e retornar à bibliografia correspondente antes de repetir a tentativa.
