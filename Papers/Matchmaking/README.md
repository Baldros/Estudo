# Matchmaking

Matchmaking estuda como agrupar jogadores ou participantes para formar interações equilibradas e satisfatórias. O problema combina estimação de habilidade, otimização combinatória, previsão de comportamento e objetivos de produto.

## Linhas de estudo

- [Estratégias orientadas a engajamento](Engagement-Strategy/README.md) - investigam retenção e experiência para além da igualdade estrita de habilidade.
- [Estratégias orientadas a habilidade](Skill-Strategy/README.md) - priorizam avaliação de força, equilíbrio das equipes e satisfação de posição.
