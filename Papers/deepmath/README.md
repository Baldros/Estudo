# Aprendizado aplicado a malhas

Este tópico explora o uso de redes neurais, grafos e aprendizado por reforço para operar sobre malhas e melhorar sua estrutura.

## Trabalhos

- *Learning Topological Operations on Meshes with Application to Block Decomposition of Polygons* - aprende operações topológicas sobre malhas e as aplica à decomposição de polígonos em blocos, aproximando decisões geométricas de métodos orientados por dados.
- *Optimizing Mesh Regularity Using Reinforcement Learning and Graph Neural Networks* - apresentação de dissertação que combina aprendizado por reforço e redes neurais de grafos para melhorar regularidade de malhas.
