# TurboQuant

TurboQuant é uma abordagem de quantização vetorial voltada a preservar geometria em vetores de alta dimensão com baixo custo de representação.

## Artigo

- *TurboQuant* - propõe rotações aleatórias e quantização independente dos dados para aproximar taxas ótimas de distorção tanto em erro quadrático quanto em produtos internos.
