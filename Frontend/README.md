# Desenvolvimento Frontend

Frontend trata da construção da camada de interação de aplicações, incluindo interface, estado, comunicação com serviços e integração com a arquitetura geral do sistema.

## Por que estudar

Conhecer o fluxo completo entre navegador, API e persistência ajuda a projetar interfaces consistentes e a compreender os compromissos de aplicações web modernas.

## Livro

- *Full-Stack React, TypeScript, and Node* - David Choi - guia de construção de aplicações web integrando React, TypeScript, Node e GraphQL, com foco em uma arquitetura pronta para implantação.
