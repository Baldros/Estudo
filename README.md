# Estudo

Este repositório organiza uma biblioteca pessoal de livros, artigos, notas, provas e outros materiais de apoio. O objetivo é manter o acervo navegável por área e por tópico, com READMEs que funcionem como mapas de estudo e bibliografias comentadas.

## Organização

A documentação segue três níveis:

1. este README apresenta o repositório e suas grandes áreas;
2. o README de cada área enumera os tópicos abordados;
3. o README de cada tópico explica o assunto, sua utilidade e os principais livros disponíveis.

Pastas de apoio, como coleções de slides, cursos, provas e solucionários, são descritas pelo README do tópico ao qual pertencem. Elas não constituem tópicos independentes apenas por armazenarem um tipo diferente de material.

## Limites deste repositório

Algumas pastas permanecem na mesma estrutura local por conveniência, mas não fazem parte deste repositório remoto:

- `Computação/`;
- `Banco de Dados/`;
- `Notas de Estudo/`.

`Notas de Estudo/` contém projetos com repositórios Git próprios. As regras do `.gitignore` impedem que essas árvores independentes sejam incorporadas acidentalmente ao histórico de `Estudo`.

## Convenção dos catálogos

Os resumos foram escritos como orientação de leitura, a partir de prefácios, introduções, sumários e informações bibliográficas disponíveis. Materiais cujo conteúdo não pôde ser identificado com segurança são descritos de forma conservadora.
